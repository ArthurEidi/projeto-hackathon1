# Auditoria B36 — vestibular de álgebra

As 33 questões têm pelo menos quatro opções. Em todas elas, cada feedback de erro informa o valor, a expressão ou a alternativa correta. A coluna de sugestões traz uma devolutiva para cada escolha. Quando o texto atual apenas refuta o valor e os dados não permitem atribuir uma estratégia ao aluno, a sugestão testa a escolha numericamente.

O cruzamento por script usou ano, número, edição e conteúdo do item. Nas 30 questões do ENEM regular, a letra marcada coincide com `correctAlternative`; há uma inconsistência de **valor** no próprio cache em 2011/180. A questão de oferta e demanda foi identificada pelo texto em 2012/166. As três questões fora desse conjunto foram confrontadas com os respectivos cadernos.
