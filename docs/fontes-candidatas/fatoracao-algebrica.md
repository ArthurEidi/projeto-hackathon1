### Candidata 1 — UFRGS 2022 (1º dia, Matemática, Questão 48)

- **Banca / Ano / Fase / Número:** UFRGS, 2022, Concurso Vestibular (1º dia — Matemática), Questão 48.
- **Página do PDF:** p. 25.
- **Caminho local do PDF e do gabarito:** `C:\Users\mkf10\projetos\provas-oficiais\ufrgs-2022-1dia\prova.pdf` e `C:\Users\mkf10\projetos\provas-oficiais\ufrgs-2022-1dia\gabarito.html`.
- **URL oficial:** `https://vestibular.ufrgs.br/cv2022/` (provas e gabaritos oficiais Coperse/UFRGS).
- **Depende de figura:** não.
- **Enunciado:**
  > Se a e b são as raízes da equação x² − 6x + 3 = 0, então o valor de (1 / (1/a + 1/b))⁻² é
- **Alternativas:**
  - (A) 2.
  - (B) 4.
  - (C) 6.
  - (D) 8.
  - (E) 10.
- **Gabarito oficial:** B.
- **Resolução:**
  Simplificando a fração algébrica:
  `1/a + 1/b = (a + b)/(ab)`. Logo `(1 / (1/a + 1/b))⁻² = (1/a + 1/b)² = ((a + b)/(ab))²`.
  Em `x² − 6x + 3 = 0`, pelas relações de Girard temos `a + b = 6` e `ab = 3`.
  Substituindo: `(6/3)² = 2² = 4`. Confere com o gabarito oficial **B**.

### Candidata 2 — UFPR 2023 (1ª fase, Matemática, Questão 10)

- **Banca / Ano / Fase / Número:** UFPR, 2023, 1ª fase (Conhecimentos Gerais), Matemática, Questão 10.
- **Página do PDF:** p. 4 (`4/34`).
- **Caminho local do PDF:** `C:\Users\mkf10\projetos\provas-oficiais\ufpr-2023-1fase\prova.pdf` (o caderno oficial `Geral.pdf` da NC/UFPR já marca o gabarito oficial com `►`).
- **URL oficial:** `https://servicos.nc.ufpr.br/documentos/ps2023/provas/Geral.pdf`
- **Depende de figura:** não.
- **Enunciado:**
  > Considere as equações a + b = c² e a + b + c = 20. Assinale a alternativa que corresponde à quantidade de triplas ordenadas (a, b, c) que satisfazem simultaneamente essas duas equações, sendo a, b, c números inteiros positivos.
- **Alternativas:**
  - a) 11.
  - b) 12.
  - c) 13.
  - d) 14.
  - e) 15.
- **Gabarito oficial:** e.
- **Resolução:**
  Substituindo `a + b = c²` na segunda equação:
  `c² + c = 20 ⇒ c² + c − 20 = 0`.
  Fatorando o trinômio: `(c + 5)(c − 4) = 0 ⇒ c = −5` ou `c = 4`.
  Como `c` é inteiro positivo, `c = 4`. Logo `a + b = 4² = 16`.
  Como `a` e `b` são inteiros positivos, `a ∈ {1, 2, …, 15}` e `b = 16 − a`, totalizando `15` triplas ordenadas.
  Confere com o gabarito oficial **e**.
