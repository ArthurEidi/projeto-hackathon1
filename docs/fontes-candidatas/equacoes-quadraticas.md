## Questão 1 — UFRGS 2018

- **Banca / Ano / Identificação:** UFRGS, 2018 (Exercício 1 da página).
- **URL do enunciado:** https://www.todamateria.com.br/funcao-quadratica-exercicios/
- **URL do gabarito:** https://www.todamateria.com.br/funcao-quadratica-exercicios/
- **Enunciado copiado:**
  > (UFRGS - 2018) As raízes da equação 2x² + bx + c = 0 são 3 e − 4. Nesse caso, o valor de b - c é
- **Alternativas copiadas:**
  - a) −26.
  - b) −22.
  - c) −1.
  - d) 22.
  - e) 26.
- **Gabarito:** e) 26.
- **Resumo para o app (<= 140 caracteres, 2 frases):**
  Adaptada (UFRGS 2018): As raízes da equação 2x² + bx + c = 0 são 3 e -4. Quanto vale b - c?
- **Conta que confirma o gabarito:**
  Pelas relações de soma e produto: `3 + (-4) = -b/2 => -1 = -b/2 => b = 2`, e `3 · (-4) = c/2 => -12 = c/2 => c = -24`. Logo, `b - c = 2 - (-24) = 26`.

## Questão 2 — Enem 2016 (2ª aplicação)

- **Banca / Ano / Identificação:** Enem, 2016, 2ª aplicação (Exercício 7 da página).
- **URL do enunciado:** https://www.todamateria.com.br/funcao-quadratica-exercicios/
- **URL do gabarito:** https://www.todamateria.com.br/funcao-quadratica-exercicios/
- **Enunciado copiado:**
  > Para evitar uma epidemia, a Secretaria de Saúde de uma cidade dedetizou todos os bairros, de modo a evitar a proliferação do mosquito da dengue. Sabe-se que o número f de infectados é dado pela função f(t) = - 2t² + 120t (em que t é expresso em dia e t = 0 é o dia anterior à primeira infecção) e que tal expressão é válida para os 60 primeiros dias da epidemia.
  >
  > A Secretaria de Saúde decidiu que uma segunda dedetização deveria ser feita no dia em que o número de infectados chegasse à marca de 1 600 pessoas, e uma segunda dedetização precisou acontecer.
  >
  > A segunda dedetização começou no
- **Alternativas copiadas:**
  - a) 19º dia.
  - b) 20º dia.
  - c) 29º dia.
  - d) 30º dia.
  - e) 60º dia.
- **Gabarito:** b) 20º dia.
- **Resumo para o app (<= 140 caracteres, 2 frases):**
  Adaptada (Enem 2016): O número de infectados é f(t) = -2t² + 120t. Em que dia chega a 1600 pela primeira vez?
- **Conta que confirma o gabarito:**
  `-2t² + 120t = 1600 => 2t² - 120t + 1600 = 0 => t² - 60t + 800 = 0`. Fatorando: `(t - 20)(t - 40) = 0`, logo `t = 20` ou `t = 40`. A marca de 1 600 é atingida pela primeira vez no 20º dia.

## Questão 3 — PUC-Rio

- **Banca / Ano / Identificação:** PUC-Rio (sem ano informado na página; Questão 3 da página).
- **URL do enunciado:** https://exercicios.brasilescola.uol.com.br/exercicios-matematica/exercicios-sobre-equacao-2-grau.htm
- **URL do gabarito:** https://exercicios.brasilescola.uol.com.br/exercicios-matematica/exercicios-sobre-equacao-2-grau.htm
- **Enunciado copiado:**
  > (Puc – Rio) As duas soluções de uma equação do 2° grau são – 1 e 1 / 3 . Então a equação é:
- **Alternativas copiadas:**
  - (A) 3x² – x – 1 = 0
  - (B) 3x² + x – 1 = 0
  - (C) 3x² + 2x – 1 = 0
  - (D) 3x² – 2x – 2 = 0
  - (E) 3x² – x + 1 = 0
- **Gabarito:** (C) 3x² + 2x – 1 = 0.
- **Resumo para o app (<= 140 caracteres, 2 frases):**
  Adaptada (PUC-Rio): Uma equação do 2º grau tem raízes -1 e 1/3. Qual equação corresponde a essas raízes?
- **Conta que confirma o gabarito:**
  `(x - (-1)) · (x - 1/3) = 0 => (x + 1)(x - 1/3) = 0 => x² + (2/3)x - 1/3 = 0`. Multiplicando por 3: `3x² + 2x - 1 = 0`.
