- **Caminho local do gabarito:** `C:\Users\mkf10\projetos\provas-oficiais\ufrgs-2022-1dia\gabarito.html`
- **URL oficial (prova):** `https://www.ufrgs.br/coperse/wp-content/uploads/2022/03/PROVAS-1o-DIA.pdf`
- **URL oficial (gabarito):** `https://vestibular.ufrgs.br/cv2022/gabaritos/`
- **Depende de figura:** não
- **Enunciado:**
  A área da região compreendida entre os gráficos das funções `f(x)` e `g(x)`, definidas por `f(x) = |x − 2| + 1` e `g(x) = −|x| + 5`, é
- **Alternativas:**
  - A) 4.
  - B) 6.
  - C) 10.
  - D) 15.
  - E) 20.
- **Gabarito oficial:** B
- **Resolução:**
  As interseções ocorrem quando `|x − 2| + 1 = −|x| + 5 ⇔ |x − 2| + |x| = 4`. Para `x ≥ 2`, `2x − 2 = 4 ⇒ x = 3` (`y = 2`); para `x ≤ 0`, `2 − 2x = 4 ⇒ x = −1` (`y = 4`).
  Os vértices do quadrilátero formado entre os gráficos são `A(−1, 4)`, `B(0, 5)`, `C(3, 2)` e `D(2, 1)` (os bicos de `g` e `f`).
  Os vetores `AB = (1, 1)` e `AD = (3, −3)` são perpendiculares (`1·3 + 1·(−3) = 0`), logo `ABCD` é um retângulo de lados `√2` e `3√2`, cuja área é `√2 · 3√2 = 6`. Confere com o gabarito oficial **B**.

### Candidata 2 (tema correlato: equação modular) — ITA 2011, Matemática, Questão 9
- **Banca / Ano / Fase:** ITA / 2011 / Exame Único (Matemática)
- **Número:** Questão 9

- **Caminho local do PDF:** `C:\Users\mkf10\projetos\provas-oficiais\ita-2011-mat\prova.pdf`
- **Caminho local do gabarito:** `C:\Users\mkf10\projetos\provas-oficiais\ita-2011-mat\gabarito.pdf`
- **URL oficial (prova):** `https://www.vestibular.ita.br/provas/matematica_2011.pdf`
- **URL oficial (gabarito):** `https://www.vestibular.ita.br/provas/gabarito_2011.pdf`
- **Depende de figura:** não
- **Enunciado:**
  O produto das raízes reais da equação `|x² − 3x + 2| = |2x − 3|` é igual a
- **Alternativas:**
  - A) −5.
  - B) −1.
  - C) 1.
  - D) 2.
  - E) 5.
- **Gabarito oficial:** A
- **Resolução:**
  Da igualdade `|u| = |v|`, temos `u = v` ou `u = −v`:
  1. `x² − 3x + 2 = 2x − 3 ⇒ x² − 5x + 5 = 0` (`Δ = 5 > 0`, duas raízes reais de produto `5`).
  2. `x² − 3x + 2 = −2x + 3 ⇒ x² − x − 1 = 0` (`Δ = 5 > 0`, duas raízes reais de produto `−1`).
  Como `x = 3/2` não anula nenhuma das quadráticas, as quatro raízes são distintas. O produto total vale `5 · (−1) = −5`. Confere com o gabarito oficial **A**.
