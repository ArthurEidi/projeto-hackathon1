## Questão 1 — UFRGS 2018

- **Banca / Ano / Identificação:** UFRGS, 2018 (Questão 4 da página).
- **URL do enunciado:** https://www.todamateria.com.br/logaritmo-exercicios/
- **URL do gabarito:** https://www.todamateria.com.br/logaritmo-exercicios/
- **Enunciado copiado:**
  > (UFRGS - 2018) Se log_3 x + log_9 x = 1, então o valor de x é
- **Alternativas copiadas:**
  - a) ∛2.
  - b) √2.
  - c) ∛3.
  - d) √3.
  - e) ∛9.
- **Gabarito:** e) ∛9.
- **Resumo para o app (<= 140 caracteres, 2 frases):**
  Adaptada (UFRGS 2018): Considere a equação log_3(x) + log_9(x) = 1. Qual é o valor de x?
- **Conta que confirma o gabarito:**
  Pela mudança de base: `log_9(x) = log_3(x) / log_3(9) = log_3(x) / 2`. Assim, `log_3(x) + (1/2)·log_3(x) = 1 => (3/2)·log_3(x) = 1 => log_3(x) = 2/3 => x = 3^(2/3) = ∛(3²) = ∛9`.

## Questão 2 — UFRGS 2017

- **Banca / Ano / Identificação:** UFRGS, 2017 (Questão 6 da página).
- **URL do enunciado:** https://www.todamateria.com.br/logaritmo-exercicios/
- **URL do gabarito:** https://www.todamateria.com.br/logaritmo-exercicios/
- **Enunciado copiado:**
  > (UFRGS - 2017) Se log_5 x = 2 e log_10 y = 4, então log_20 y/x é
- **Alternativas copiadas:**
  - a) 2
  - b) 4
  - c) 6
  - d) 8
  - e) 10
- **Gabarito:** a) 2.
- **Resumo para o app (<= 140 caracteres, 2 frases):**
  Adaptada (UFRGS 2017): Sabendo que log_5(x) = 2 e log_10(y) = 4. Quanto vale log_20(y/x)?
- **Conta que confirma o gabarito:**
  `log_5(x) = 2 => x = 5² = 25`, e `log_10(y) = 4 => y = 10^4 = 10 000`. Logo, `y/x = 10 000 / 25 = 400`, e `log_20(400) = log_20(20²) = 2`.

## Questão 3 — UFRGS 2016

- **Enunciado copiado:**
  > (UFRGS - 2016) Se 10^x = 20^y , atribuindo 0,3 para log 2, então o valor de x/y é
- **Alternativas copiadas:**
  - a) 0,3.
  - b) 0,5.
  - c) 0,7.
  - d) 1.
  - e) 1,3.
- **Gabarito:** e) 1,3.
- **Resumo para o app (<= 140 caracteres, 2 frases):**
  Adaptada (UFRGS 2016): Sabendo que 10^x = 20^y e usando log 2 = 0,3. Quanto vale a razão x/y?
- **Conta que confirma o gabarito:**
  Aplicando `log_10`: `x · log 10 = y · log 20 => x · 1 = y · (log 2 + log 10) = y · (0,3 + 1) = 1,3y => x/y = 1,3`.

### Candidata 1 — UFRGS 2022 (1º dia, Matemática, Questão 49)

- **Banca / Ano / Fase / Número:** UFRGS, 2022, Concurso Vestibular (1º dia — Matemática), Questão 49.
- **Página do PDF:** p. 26.
- **Caminho local do PDF e do gabarito:** `C:\Users\mkf10\projetos\provas-oficiais\ufrgs-2022-1dia\prova.pdf` e `C:\Users\mkf10\projetos\provas-oficiais\ufrgs-2022-1dia\gabarito.html`.
- **URL oficial:** `https://vestibular.ufrgs.br/cv2022/` (provas e gabaritos oficiais Coperse/UFRGS).
- **Depende de figura:** não.
- **Enunciado:**
  > Se log₂ x + (log₂ x)² = 12, então o valor de x é
- **Alternativas:**
  - (A) 8 ou 1/16.
  - (B) 1/8 ou 16.
  - (C) −4 ou 3.
  - (D) 4 ou −3.
  - (E) 2¹².
- **Gabarito oficial:** A.
- **Resolução:**
  Condição de existência: `x > 0`. Fazendo `y = log₂ x`, temos `y² + y − 12 = 0 ⇒ (y + 4)(y − 3) = 0 ⇒ y = 3` ou `y = −4`.
  - Para `y = 3`: `log₂ x = 3 ⇒ x = 2³ = 8`.
  - Para `y = −4`: `log₂ x = −4 ⇒ x = 2⁻⁴ = 1/16`.
  Ambos satisfazem `x > 0`. Confere com o gabarito oficial **A**.

- **Enunciado:**
  > Se x = 9 log₁₂₀ 2 + 3 log₁₂₀ 3 + 2 log₁₄₄₀₀ 125 podemos afirmar que
- **Alternativas:**
  - A) x = 2.
  - B) x = 3.
  - C) x = 4.
  - D) x = 5.
  - E) x = 6.
- **Gabarito oficial:** B.
- **Resolução:**
  Como `14 400 = 120²` e `125 = 5³`, temos `2 log₁₄₄₀₀ 125 = 2 · (1/2) · log₁₂₀(5³) = log₁₂₀(5³)`.

  Confere com o gabarito oficial **B**.
