### Candidata 1 — ITA 2021 (1ª fase, Matemática, Questão 42)

- **Banca / Ano / Fase / Número:** ITA, 2021, 1ª fase, Matemática, Questão 42.
- **Página do PDF:** p. 14.
- **Caminho local do PDF e do gabarito:** `C:\Users\mkf10\projetos\provas-oficiais\ita-2021-1fase\prova.pdf` e `C:\Users\mkf10\projetos\provas-oficiais\ita-2021-1fase\gabarito.pdf`.
- **URL oficial:** `https://www.vestibular.ita.br/` (acervo oficial de provas e gabaritos ITA 2021).
- **Depende de figura:** não.
- **Enunciado:**
  > Seja S ⊂ ℝ o conjunto solução da inequação (x² + x + 1)^(2x²−x−1) ≤ 1. Podemos afirmar que:
- **Alternativas:**
  - A) S = [−1, 1].
  - B) S = [−1, −1/2].
  - C) S = [0, 1].
  - D) S = [−1, −1/2] ∪ [0, 1].
  - E) S é o conjunto vazio.
- **Gabarito oficial:** D.
- **Resolução:**
  Como `x² + x + 1 = (x + 1/2)² + 3/4 > 0` para todo `x ∈ ℝ`, vale a equivalência de sinais:
  `a^b ≤ 1 (a > 0) ⇔ (a − 1) · b ≤ 0`.
  Logo a inequação reduz-se à inequação-produto:
  `(x² + x)(2x² − x − 1) ≤ 0 ⇔ x(x + 1)(2x + 1)(x − 1) ≤ 0`.
  As raízes simples ordenadas são `−1 < −1/2 < 0 < 1`, e o coeficiente líder é `2 > 0`.
  Pelo quadro de sinais, o produto é `≤ 0` exatamente em `S = [−1, −1/2] ∪ [0, 1]`.
  Confere com o gabarito oficial **D**.
